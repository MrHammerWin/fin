## Границы

Поддерживаются согласованные шаблоны проекта. Универсальная обработка всех текстов и таблиц не реализуется. PDF-шаблоны одностраничные; сканы могут требовать исправления оригинала. Ожидаемые даты и внутренние ID старых шаблонов, которых в файлах не было, отмечаются как сохранённые ручные настройки и привязки. Денежные суммы и даты признания из модели генератора не подставляются.

Начисления формируются по актам; план и факт оплаты не смешиваются. Большой CSV-корпус хранится отдельно от основных обработанных документов и автоматически целиком не включается в браузерный календарь. Ручные оплаты браузерной демонстрации не стали постоянными записями в БД.

## Причины изменений

| Изменение | Основание |
| --- | --- |
| Удалены запись выходных форматов, API/страница конвертера и зависимость от LibreOffice | Пользователь отказался от конвертации |
| Сохранены низкоуровневые читатели OOXML/CSV/PDF и OCR | Нужны для чтения финансовых шаблонов из содержимого файлов |
| Добавлены читатель полей и единый финансовый импорт | Раньше договоры, счета и акты брали финансовые данные из модели генератора |
| Расчёт и проверка повторов используют прочитанные реквизиты | Требуются настоящие данные источников, сверка связей и отсутствие двойного учёта |
| Новые шаблоны содержат ID обязательства и ожидаемую дату | Эти поля отсутствовали в старых исходниках; их нельзя выдавать за извлечённые |
| Просмотр, подтверждение и атомарное применение | По выбору пользователя загруженные документы включаются в расчёт после проверки |
| Проверка хешей, откат, сохранение оригиналов и корпуса | Устаревшее подтверждение, ошибка или отмена не должны менять текущие данные |
| Повторная очистка частично удалённого набора | На Windows занятый файл может остаться после удаления dataset.json; отдельный маркер сохраняет принадлежность папки для повторной очистки |
| Генератор и регулирование объёма сохранены | Изменился запрос к работе с документами, а не к объёму данных |
